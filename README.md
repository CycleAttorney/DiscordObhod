>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, Kaspersky содержит настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройку исключений, предпочтительно добавить исключение; при сомнениях отключите обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от варианта "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и укажите URL вручную. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы; [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно

2. Откройте [страницу последнего релиза](https://github.com/CycleAttorney/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar

3. В свойствах архива отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить запуск вместе с системой, выберите **`service.bat`** -> `Install Service` -> нужную стратегию

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **переберите стратегии ALT, FAKE и другие, пока не найдёте подходящую для своей системы**

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других программ, использующих UDP и TCP-порты выше 1023.  
  **После смены параметра стратегию нужно запустить заново.**  
  Состояние функции отображается в скобках: включено или выключено.
  - **`IPSet Filter`** - настройка режима обхода для ресурсов из `ipset-all.txt`.  
  Это помогает при диагностике ресурса, который без zapret доступен, а с ним перестаёт открываться.  
  В скобках выводится текущий режим:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - ручная проверка наличия новой версии
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В финале доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, которая иногда возвращает работоспособность после внезапного сбоя
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/CycleAttorney/zapret-discord-youtube/issues/522)

### Не подошла ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезапустите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - С правами администратора откройте текстовый редактором файл `hosts` в созданной папке
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Совместимость не гарантируется. При отсутствии результата установите [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/CycleAttorney/tg-ws-proxy) или любой публичный прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Рабочие стратегии могут со временем перестать работать.**
> Стратегия иногда действует некоторое время, а затем перестаёт справляться после её обнаружения.
> В этом репозитории собрано много вариантов обхода. Если готовые варианты не помогают, создайте собственную стратегию на базе одной из них и измените параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` -> `Run Diagnostics` и проверьте наличие ошибок

- Убедитесь, что нужный адрес присутствует в доменных списках или списках IP

- Запустите другие варианты, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/CycleAttorney/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; устраните найденные ошибки и в конце подтвердите действие клавишей Y
- Удалите старый каталог zapret
- Скачайте свежую версию на [странице релизов](https://github.com/CycleAttorney/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа доступна кнопка разблокировки, нажмите её, затем выберите применить и ОК
- Распакуйте файлы в новый каталог в корне диска, избегая пробелов и специальных символов
- Поочерёдно проверяйте различные скрипты `general`. Если интернет-ресурс не открывается, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Проверьте в service.bat, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал против них активно бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительное обсуждение: [#251](https://github.com/CycleAttorney/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия тоже недоступна, снова протестируйте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/CycleAttorney/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/CycleAttorney/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите режим `ipset any`

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Поэтому не оставляйте этот режим включённым постоянно. Выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результат не изменился, создайте обсуждение в разделе [Discussions](https://github.com/CycleAttorney/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [в issue](https://github.com/CycleAttorney/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не следует
- **`ipset-all.txt`** - отдельные IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключаемые из обработки
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
